## 3. 핵심 배운 점 및 요약 패턴

### 문제 1: 자동차 대여 기록에서 장기/단기 대여 구분하기
- **당일 포함 날짜 차이 계산**: 대여 기간 계산 시 시작일을 포함해야 하므로 `DATEDIFF(END_DATE, START_DATE) + 1`을 적용해야 합니다.
- **날짜 포맷 통일**: 문제 요구사항 및 예시 출력 형식에 맞추어 `DATE_FORMAT(..., '%Y-%m-%d')` 처리를 진행합니다.

### 문제 2: 조건별로 분류하여 주문상태 출력하기
- **CASE WHEN 분기 처리**: NULL 데이터는 비교 연산 시 UNKNOWN을 반환하므로 `WHEN OUT_DATE <= '2022-05-01' THEN '출고완료' WHEN OUT_DATE > '2022-05-01' THEN '출고대기' ELSE '출고미정'` 또는 `IS NULL` 검사를 명시적으로 활용합니다.

### 문제 3: 멸종위기의 대장균 찾기
- **WITH RECURSIVE 재귀 CTE**: 부모-자식 계층형 구조에서 루트 개체(`PARENT_ID IS NULL`)를 1세대로 초기화한 뒤 `JOIN`을 통해 각 개체의 세대(`GENERATION + 1`)를 재귀적으로 추적합니다.
- **자식이 없는 리프 노드 선별**: 부모 개체 기준 자식 개체를 Self `LEFT JOIN` 결합하여 자식 개체의 키가 매칭되지 않는(`child.ID IS NULL`) 조건을 통해 자식이 없는 개체만을 집계합니다.
